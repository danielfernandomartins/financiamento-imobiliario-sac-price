# 🏠 Simulador de Financiamento Imobiliário — SAC e Price

Projeto em Python voltado à simulação de financiamento imobiliário com comparação entre os sistemas de amortização **SAC** e **Price**.

## Visão do projeto

A aplicação foi criada para transformar regras financeiras em uma ferramenta prática de simulação, permitindo visualizar parcelas, juros, amortização e saldo devedor ao longo do contrato.

O projeto conecta conhecimento de **serviços financeiros e crédito** com lógica de programação.

## Funcionalidades

- Cálculo de parcelas pelo sistema SAC
- Cálculo de parcelas pela Tabela Price
- Conversão de taxa anual para taxa mensal efetiva
- Geração de tabela de amortização
- Simulação de amortizações extraordinárias
- Exportação dos resultados em CSV
- Exibição detalhada de juros, amortização e saldo devedor
