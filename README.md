Simulador de Financiamento Imobiliário (SAC e Price)

Descrição:

Este projeto é um simulador de financiamento imobiliário em Python, que permite calcular parcelas e gerar a tabela de amortização de acordo com os dois sistemas mais usados no Brasil:
Tabela Price: parcelas fixas, juros maiores no início.
SAC (Sistema de Amortização Constante): amortização constante, parcelas decrescentes.

O programa também permite:

Inserir amortizações extraordinárias (pagamentos adicionais).
Exportar a tabela completa em CSV.
Escolher taxa de juros mensal ou anual.

Funcionalidades:

Cálculo de parcelas e juros mês a mês.
Geração de tabela de amortização detalhada.
Suporte a amortizações extras.
Exportação da tabela para CSV.
Menu interativo amigável.
Cálculo automático da taxa efetiva mensal a partir de uma taxa anual.

Tecnologias:

Linguagem: Python 3.x

Bibliotecas: decimal, dataclasses, csv, typing (todas inclusas na biblioteca padrão do Python)

Como Usar:

Pré-requisitos:
Python 3 instalado no seu sistema.
Um terminal ou prompt de comando.
